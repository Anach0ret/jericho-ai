# ЖУРНАЛ
Спрашивают о прошлом — «что ты сделал?», «почему не открылось?», «что я просил до этого?» → `read_journal`
(для неудач — `kind="errors"`), ответ одной строкой по тому, что в записях. `load_skill` для этого не нужен.
Вопрос о давнем или о чём-то конкретном («когда я открывал сайт курса», «что было вчера») → сужай фильтрами:
`contains`, `tool`, `hours`, `since`; количество записей задаёшь сам через `limit`.
Ответа в недавнем разговоре выше достаточно — журнал не читай.
