# Проверочные фразы

Набор фраз, по которому видно, не стало ли хуже после правки промпта, ручек или самого каркаса.

## Где лежат
- `<пакет проекта>/skills/<навык>/evals.md` — фразы навыка; в прогон идут только подключённые навыки;
- `src/jericho/core/prompting/evals.md` — фразы, которые не относятся ни к одному навыку.

## Как запускать
```
<проект> eval --list            # какие фразы в наборе
<проект> eval                   # весь набор: оценка, сравнение с прошлым прогоном, запись
<проект> eval desktop:11 core:16   # только названные фразы; с прошлым прогоном не сравнивается
```
Прогон идёт через настоящую модель, но «вхолостую» (вариант настроек `Eval`): меняющие команды не выполняются,
а только записываются. У прогона свои папки (`state_name` варианта `Eval`): свой журнал, своя память разговора
и записи прогонов в `runs/`. Читающие команды выполняются по-настоящему, поэтому часть ответов зависит от того,
что сейчас вокруг; такие фразы допускают несколько статусов. Прогон стоит запросов к модели.

## Формат строки
`# | Фраза | Ручки | Статус | После | Заметка`

| Колонка | Что писать |
|---|---|
| Ручки | `—` — ни одной; `open_app {"workspace": 3}` — вызов и важные параметры; несколько — через `;`; `hyprctl?` — вызов допустим, но не обязателен; `close_windows !needs_confirm` — вызов, который должен отказать этим кодом |
| Статус | `done`, `clarify`, `refused`, `ignored`; несколько — через `/` |
| После | номер фразы, после которой эта идёт в том же разговоре («да» после вопроса) |

Параметры сравниваются только названные: `{"project": "portfolio"}` годится для любого стола.
Фраза, которой нужна неподключённая ручка, должна получить `refused` без вызовов — это подставляется само.
В составной фразе («открой проект и включи музыку»), где часть ручек подключена, ждём то, что сделать можно;
о несделанном модель говорит в сообщении.

## Что оценивается
| Критерий | Проходит, если |
|---|---|
| ручки | вызваны ровно те ручки, что нужны: ни лишней, ни пропущенной |
| параметры | у каждого ожидаемого вызова названные параметры совпали |
| исход | ожидаемые вызовы прошли успешно (или отказали записанным кодом), и ответа `done` нет поверх неожиданного отказа |
| статус | статус ответа — один из ожидаемых |
| сообщение | текст для уведомления не длиннее 80 знаков |

## Правила
- Набор фиксирован: номера фраз не переиспользуются, ожидания записаны до прогона.
- За одну правку меняется одно — иначе не понять, что повлияло.
- Перед шагом, который меняет поведение, — прогон «до», после него — прогон «после».

Журнал прогонов ведёт проект у себя, например в `docs/evals-log.md`.
