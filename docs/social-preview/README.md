# Изображение для предпросмотра GitHub

`jericho-social.png` — готовое изображение 1280×640, PNG RGB, без прозрачности. Оно предназначено для
Social preview репозитория и не требует вставки большого баннера в README.

`jericho-social.svg` — редактируемый исходник. Текст: название, назначение каркаса, политика риска,
подтверждения и журнал. Схема упрощённая: она показывает путь вызова, а не все слои исполнения.

Для текста использован Google Sans Flex (должен быть установлен при повторном рендере SVG).
Шрифт в PNG уже отрисован, установка шрифта пользователю или GitHub не требуется.

Пересборка с ImageMagick:

```bash
magick -background '#f4f2e9' docs/social-preview/jericho-social.svg -alpha remove -alpha off -depth 8 -strip PNG24:docs/social-preview/jericho-social.png
```

Стрелки выполнены залитыми прямоугольниками и треугольниками: используемый рендерер ImageMagick терял
соединители на stroke/marker. Эти элементы нельзя заменять маркерами без проверки PNG.

После изменения SVG нужно пересобрать и осмотреть PNG: рендереры SVG могут по-разному обрабатывать шрифты.
Готовое изображение осмотрено локально в размере 1280×640. Предпросмотр реальной карточки внешнего сервиса
не проверялся.

Загрузка владельцем: настройки репозитория GitHub → General → Social preview → Edit → Upload an image.
После загрузки внешние сервисы могут некоторое время показывать старую картинку из своего кэша.
