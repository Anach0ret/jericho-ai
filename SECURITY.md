# Безопасность

Каркас обещает конкретные вещи — они перечислены в [docs/security.md](docs/security.md) с тем, кто их держит и
чем они проверены. Уязвимость — это нарушение одного из этих обещаний: например, действие `EFFECT` без «да»,
личные поля в журнале или у недоверенной модели, файл вне разрешённых корней, «да» одного пользователя,
подтвердившее вопрос другого.

## Как сообщить

**Не открывайте публичный issue.** Напишите через
[GitHub Security Advisories](../../security/advisories/new) этого репозитория («Report a vulnerability»): что
нарушено, как повторить, версия каркаса. Отвечу, как только смогу; это личный проект без сроков поддержки.
Исправление выходит отдельной версией со строкой «**Строже:**» в `CHANGELOG.md`.

## Что не считается уязвимостью каркаса

- То, что `docs/security.md` прямо относит к автору навыка (отметка чужого текста, идемпотентность ручки,
  запрет, собранный из разрешённых ручек) или в раздел «Чего каркас не обещает».
- Код навыка, который действует мимо ручек: каркас рассчитан на навыки, которые принимает человек.

---

**English.** Please do not open a public issue. Report privately via GitHub Security Advisories ("Report a
vulnerability") with what is broken, how to reproduce it and the framework version. The promises are listed in
`docs/security.md`.
